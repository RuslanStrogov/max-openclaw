# Архитектура MAX OpenClaw Plugin

## Общая схема

```
┌──────────────┐   MAX Bot API    ┌──────────────────┐   OpenClaw    ┌──────────────┐
│              │ ←──────────────  │                  │   Gateway     │              │
│  MAX Client  │                  │  max-openclaw    │ ──────────►   │  AI Agent    │
│  (iOS/Web)   │ ──────────────►  │  Plugin (Node)   │               │  (Hermes и   │
│              │   webhook POST   │                  │               │   др.)       │
└──────────────┘                  └──────────────────┘               └──────────────┘
```

## Компоненты

### 1. MaxClient (src/client.ts)

Обёртка над HTTP API MAX. Отвечает за:
- Отправку сообщений всех типов (текст, фото, файлы, аудио)
- Индикатор печати
- Обработку callback-запросов
- Загрузку файлов через upload API

### 2. Event Handler (src/handler.ts)

Процессор входящих webhook-событий:
- Приём и валидация webhook (HMAC-SHA256)
- Парсинг событий (message_new, message_callback)
- Фильтрация по allowlist
- Преобразование в OpenClaw-совместимый формат

### 3. Plugin Bootstrap (src/index.ts)

Точка входа — регистрация плагина в OpenClaw Gateway:
- Загрузка конфигурации
- Регистрация канала
- Настройка webhook-сервера (если включён встроенный)

### 4. DM Security (src/dm.ts)

Система безопасности для личных сообщений:
- **pairing** — подтверждение через код верификации
- **allowlist** — только из белого списка
- **open** — любые сообщения
- **disabled** — DM отключён

## Поток сообщения

```
1. Пользователь пишет в MAX
2. MAX → POST webhook на сервер плагина
3. Плагин валидирует подпись (HMAC)
4. Плагин проверяет allowlist
5. Плагин передаёт сообщение в OpenClaw Gateway
6. Gateway направляет AI-агенту
7. Ответ агента → плагин → MAX Bot API → пользователь
```

## Безопасность

- **HMAC-SHA256** — каждый webhook подписывается секретным ключом
- **Allowlist** — белый список user_id
- **DM Policy** — настройка приватности для каждого чата
- **Rate limiting** — ограничение запросов от одного пользователя
